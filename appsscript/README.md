# 웹앱 · 초진기록 (Google Apps Script)

상담 통합 대시보드 웹앱과 초진기록 자동화 코드입니다. 실제로 돌아가는 원본은
Google Apps Script 프로젝트이고(clasp 로 배포), 이 폴더는 공개용 사본입니다.

| 파일 | 내용 |
|---|---|
| `Code.js` | 웹앱 서버 — 대시보드 · 금일 현황 · 수집 중단 감시 |
| `Index.html` | 웹앱 화면 — 실시간 현황 / 초진기록 탭 |
| `초진기록.js` | 매일 저녁 9시 초진콜·카톡·합계 기록, 웹앱용 조회 |
| `초진분석.js` | 연도별 드라이브 'N월 전화내역' 으로 지난 기록 채우기 |
| `채널.js` | 유입 채널(초진콜 하위 구분 · 카톡 채널) 기록 · 조회 |
| `강언바비톡잔액.js` | 강남언니 · 바비톡 잔액 확인 |

## 공개 사본에서 지운 값

메일 주소는 `alert@example.com`, 구글 시트 · 폴더 · 스크립트 ID 는 `YOUR_GOOGLE_ID`
로 바꿔 두었습니다. 그대로 쓰려면 자기 값으로 채워야 합니다.

올리기는 원본 폴더에서 `python publish_appsscript.py "메모"` 로만 합니다 —
이 폴더의 파일을 직접 고치면 다음에 덮어써집니다.

## 업데이트 내역

### 2026-11-16 · 카카오 예약 확인 체크 · 예약대기

카카오 예약은 관리자 화면에서 '확정 / 취소' 둘 중 하나만 고를 수 있어서, 고객이 전화를
안 받으면 우리가 확인했어도 미확인 상세에 계속 남았다. 이를 대시보드에서 정리할 수 있게 했다.

- **확인 체크** — 미확인 상세의 카카오톡 **예약** 행에만 '확인' 체크박스가 있다.
  체크하면 목록에서 빠지고 미확인 건수 · 알람 건수도 함께 줄어든다.
- **예약대기 n명** — 체크한 건은 카카오톡 박스에 노란 배지로 모인다(아직 확정 · 취소 전이라는 뜻).
  카카오 관리자에서 확정 · 취소하면 수집 목록에서 빠지므로 배지에서도 저절로 사라진다.
- **되돌리기** — 배지를 누르면 명단이 펼쳐지고, 잘못 체크한 건은 [되돌리기]로 미확인 목록에 다시 올린다.
  행에 마우스를 올리면 연락처 · 신청시각이 보여 동명이인을 구분할 수 있다.
- **모든 PC 공유** — 체크 기록은 스크립트 속성(`kakao_resv_ack`)에 저장돼 모든 PC · 탭에 같이 반영된다.
  60일 지난 기록은 자동으로 지운다. 전체 초기화는 편집기에서 `RESET_카톡예약확인` 실행.
- 같은 건인지는 `채널 | 이름 | 신청일시 | 연락처` 로 판단한다. 같은 고객이 예약을 새로 신청하면
  신청일시가 달라 다시 미확인으로 올라온다.

관련 코드: `Code.js` 의 `applyAcks_` · `ackKakaoReservation` · `unackKakaoReservation`,
`Index.html` 의 `waitingHtml` · 체크/되돌리기 이벤트.
